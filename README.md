# AI-Powered Sports Talent Assessment

QUANTEX'26 hackathon project. A webcam-based prototype that uses pose estimation to count push-ups and check form, helping make sports screening accessible to rural and underserved athletes.

## Tech Stack
Python, MediaPipe, OpenCV, NumPy, Streamlit, SQLite, Pandas

## Status
Prototype in development.

##View the current status of our project
https://sports-talent-assessment.streamlit.app/

## How to Run the Python file
```bash
pip install -r requirements.txt
streamlit run app.py
```
